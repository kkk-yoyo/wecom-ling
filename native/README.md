# native/bin

本目录存放 `微灵.exe` 运行所必需的两个 x86 原生组件（从原作者发布包中原样提取）：

| 文件 | 说明 |
| --- | --- |
| `Loader.dll` | 注入器 / socket 宿主，主程序按固定偏移调用（19216 / 20096 / 20688 / 22528） |
| `Helper_5.0.0.6008.dll` | 注入到企业微信 5.0.0.6008 进程的 hook 核心 |

使用方法：把这两个 DLL 与 `dist/微灵.exe`（或自行编译的 `WeComSever.exe`）放到**同一目录**后运行。

接口与偏移详见 [`docs/NATIVE_DLLS.md`](../docs/NATIVE_DLLS.md)。
